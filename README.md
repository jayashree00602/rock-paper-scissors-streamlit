# 🎮 Rock Paper Scissors Web App

This is an interactive Rock Paper Scissors game built using Python and Streamlit.

## 🚀 Features
- Single Player (vs Computer)
- Two Player Mode
- Multi Player Mode
- Score Tracking System
- Target Score Feature
- Interactive UI with emojis & GIFs

## 🛠️ Technologies Used
- Python
- Streamlit

## ▶️ How to Run
pip install streamlit  
streamlit run app.py
